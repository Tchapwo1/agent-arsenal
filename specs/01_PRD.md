# 🎯 Pillar 1: Product Requirements Document (PRD) — Agent Arsenal

## Executive Summary
**Agent Arsenal** is an elite, open-source skill suite and CLI package for AI coding agents (Cursor, Claude Code, Windsurf, Copilot, Antigravity, Cline). It cures the three universal pain points of modern AI coding: **agent code bloat**, **sloppy architectural hygiene**, and **context amnesia**.

Inspired by the astronomical rise of Matt Pocock’s skills repo (30K stars) and ponytail (24K stars), Agent Arsenal packages 10 field-tested, zero-dependency engineering skills coupled with an instant CLI (`npx agent-arsenal add <skill>`) that installs them directly into `.cursorrules`, `.agent/skills/`, or `.claude/skills/`.

---

## 🎯 Target Audience
1. **AI-First Engineers & Founders:** Developers using Cursor, Claude 3.7 Sonnet, and Windsurf who want agents to write tight, production-grade code rather than 400 lines of boilerplate.
2. **Tech Leads & Maintainers:** Teams tired of reviewing messy, bloated PRs generated by AI tools.
3. **Open-Source Builders:** Creators looking for drop-in skills for diagrams, security checks, and UI polish.

---

## 💎 The 10 Superpower Skills
1. `anti-bloat`: Forces agents to write minimal code (60% less lines), eliminate unnecessary wrapper classes, and avoid adding redundant npm packages.
2. `diagram-craft`: Produces elegant ASCII architecture diagrams, Mermaid charts, and SVG flowcharts for technical documentation.
3. `security-shield`: Scans proposed agent diffs for exposed API keys, SQL vulnerabilities, SSRF vectors, and prompt injections before committing.
4. `apple-polish`: Implements Apple/Linear-grade design tokens (typography hierarchy, optical padding, dark mode elevation, tactile microcopy).
5. `reverse-engineer`: Deconstructs raw curl traces, API JSON responses, and DOM structures into clean, typed TypeScript interfaces and Zod schemas.
6. `git-surgeon`: Compresses chaotic agent trial-and-error commits into atomic, conventional commits with detailed PR descriptions.
7. `sql-optimizer`: Restricts agents to index-aware SQL queries, eliminates N+1 patterns, and guarantees safe migration rollbacks.
8. `api-contract`: Enforces strict type parity and Zod/Pydantic validation contracts between client and server interfaces.
9. `copy-surgeon`: Detects and eliminates dead giveaway AI buzzwords (*"delve", "testament", "tapestry", "seamlessly", "furthermore"*) from UI and docs.
10. `test-sniper`: Crafts surgical edge-case and boundary tests rather than trivial happy-path tests that create false confidence.

## 🚀 Key Features & Out of Scope
### In Scope (v1.0):
- 10 standalone, zero-dependency Markdown skill definitions with YAML frontmatter.
- Universal CLI tool (`npx agent-arsenal`):
  - `list`: Interactive terminal catalog with colorized descriptions.
  - `add <skill>`: Detects workspace (Cursor, Claude, Windsurf, Antigravity) and writes to target folder.
  - `add --all`: Installs the complete suite in one shot.
  - `audit`: Analyzes a local prompt or repository for agent bloat risks.
- One-click copy snippets for README and direct `.cursorrules` drop-in.

### Out of Scope:
- Cloud-hosted SaaS or required API keys (100% local, privacy-first, zero telemetry).
- Proprietary runtime dependencies.
